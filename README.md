# Minimap Pinger

Mute the minimap ping sound in the parts of World of Warcraft where you do not want to hear it. Choose separately for the open world, dungeons, raids, scenarios and Delves, battlegrounds, and arenas. Ping markers remain visible.

## Install

Copy this folder into `World of Warcraft/_retail_/Interface/AddOns/` as `MinimapPinger`, then restart the game or use `/reload`.

## Configure

Type `/mmp` or open **Options → AddOns → Minimap Ping Sound**. Check the places where you want the sound muted. All options are off by default, and your choices are saved between sessions.

The addon mutes sound file ID `567416`. Other game alerts that use that same sound may also be silenced while a mute option is active.

## Compatibility

Retail WoW 12.1.5 (`## Interface: 120105`). Classic clients are not supported.
